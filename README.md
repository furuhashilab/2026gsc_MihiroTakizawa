# Introduction（何を研究したのか、なぜ研究したのか）

本研究では、生成AIを活用した高校生・大学生向け自己理解・キャリア探索支援システムを提案する。

近年、新卒社員の早期離職や企業とのミスマッチが社会課題となっており、その背景には自己理解が不十分なまま進路選択や就職活動を行っていることがあると考えられる。また、自己理解は一人で進めることが難しく、キャリアカウンセラーなど第三者との対話が有効である一方、利用機会には時間や場所などの制約がある。さらに、進路選択の参考となるロールモデルとの出会いにも地域や情報格差が存在する。

そこで本研究では、生成AIを活用し、自己理解の促進とロールモデルの提示を組み合わせたキャリア探索支援システムを提案し、その有効性を検証する。

---

# Methods（何をしたのか）

本研究では、生成AIを用いた自己理解・キャリア探索支援システムのプロトタイプを開発した。

システムは、利用者との対話を通じて過去の経験や価値観、興味、強みを整理し、自己理解を促進する機能を備える。また、対話内容をもとに、利用者に近い価値観や経験を持つロールモデルを提示し、進路やキャリアの選択肢を広げることを目的とした。

開発したシステムを高校生または大学生に利用してもらい、アンケートやインタビューを実施することで、自己理解や進路選択への影響を評価した。

---

# Results（何がわかったのか）

利用者評価の結果、生成AIとの対話は自身の価値観や強みを整理するきっかけとなり、自己理解を深めることに一定の効果があることが示された。

また、自分と似た価値観や経験を持つロールモデルを提示することで、これまで知らなかった進路や職業への興味を持つ利用者も見られた。

一方で、AIの回答内容やロールモデルの提示精度については改善の余地があることも明らかとなった。

> **※ 実験前の場合は、この章は利用者評価後に実際の結果を記述する。**

---

# Discussion（結果は何を意味するのか）

本研究の結果から、生成AIは自己理解を支援する対話相手として活用できる可能性が示された。

また、ロールモデルを組み合わせることで、自己理解だけでなく、将来の選択肢を広げる支援にもつながることが示唆された。

一方で、利用者に適した質問の設計やロールモデル提示の精度向上が今後の課題である。

さらに、生成AIは進路を決定するものではなく、利用者自身が主体的に考え、意思決定するための支援ツールとして活用することが重要である。

---

# Conclusion（何を学んだのか・今後の課題）

本研究では、生成AIを活用した自己理解・キャリア探索支援システムを提案し、自己理解の促進とロールモデルの提示を組み合わせることで、進路・キャリア選択を支援できる可能性を示した。

生成AIは時間や場所を問わず利用できるため、自己理解やキャリア支援の機会格差を軽減できる可能性がある。

今後は、ロールモデルデータの充実やAIの対話品質の向上、より多くの利用者を対象とした評価実験を実施し、システムの有効性をさらに検証していく必要がある。

概要
本研究では、生成AIを活用した高校生および大学生向け自己理解・キャリア探索支援システムを提案する。近年、新卒社員の早期離職や企業とのミスマッチが社会課題となっており、その要因の一つとして、自身の価値観や強み、興味を十分に理解しないまま進路や就職先を選択していることが考えられる。自己理解は、就職活動における自己分析や自己PR、志望動機の作成だけでなく、高校卒業後の進学や就職など、人生における重要な進路選択の基盤となる。しかし、自己理解を一人で深めることは難しく、キャリアカウンセラーなど第三者との対話によって理解が深まることが多い。一方で、キャリア支援には時間や場所、利用機会などの制約があり、誰もが継続的に利用できる環境とは言えない。また、自分に近い価値観や経験を持つロールモデルとの出会いは進路選択の参考となる一方、その機会には地域や情報環境による格差が存在する。そこで本研究では、生成AIとの対話を通じて利用者の価値観や強み、興味を整理し、自己理解を促進するとともに、利用者に近いロールモデルを提示するシステムを開発する。これにより、時間や場所を問わず、誰もが気軽に自己理解を深め、多様な進路やキャリアの選択肢を知ることができる環境の実現を目指す。さらに、プロトタイプの開発と利用者評価を通じて、本システムが自己理解の促進および進路・キャリア選択に与える効果を検証する。 

Introduction

近年、大学生のキャリア形成において、自分自身の興味や強みを理解し、将来の選択肢を考えることの重要性が高まっている。一方で、「やりたいことが分からない」「自分に向いていることが分からない」といった悩みを抱える学生も多い。また、キャリアについて相談できる人や、自分に近い経験を持つロールモデルに出会う機会は、所属する環境や人間関係によって左右される。本研究では、生成AIを活用し、対話を通じて自己理解を促すとともに、利用者の価値観や経験に近いロールモデルを提示するキャリア探索支援システムを提案する。

Methods

本研究では、大学生を対象とした生成AIによる自己理解支援システムのプロトタイプを制作する。システムでは、利用者との対話を通じて、過去の経験、興味、得意なこと、価値観などを収集する。AIは入力された情報を整理し、利用者自身が自分の特徴を理解するためのフィードバックを提示する。また、あらかじめ収集・整理したロールモデルのキャリア情報をもとに、利用者の特徴に近い人物や経験例を紹介する。完成したプロトタイプを大学生に利用してもらい、自己理解への影響や有用性について評価を行う。

Results

（※実験後に書く部分）

本システムを利用した結果、利用者は自身の経験や価値観を振り返るきっかけを得ることができた。また、ロールモデルの提示によって、将来のキャリアに対する具体的なイメージや選択肢の広がりが確認された。一方で、AIによる質問内容や提示される情報の精度について改善点も明らかになった。

Discussion

本研究の結果から、生成AIはキャリア選択の答えを提示するものではなく、利用者自身が考えを整理するための対話相手として活用できる可能性が示された。また、ロールモデルを提示することで、自分とは異なる人生の選択肢を知る機会を提供できると考えられる。一方で、AIによる判断が利用者の可能性を限定しないよう、情報提示の方法や質問設計について慎重に検討する必要がある。

Conclusion

本研究では、生成AIを活用した自己理解・キャリア探索支援システムを提案した。本システムを通じて、大学生が自身の経験や価値観を振り返り、将来の選択肢を広げるための支援方法について検討した。今後は、より多様なロールモデル情報の収集や、利用者の属性に応じた質問設計を行うことで、さらに効果的なキャリア支援システムへの発展が期待され
